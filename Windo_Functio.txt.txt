Find Month-over-Month Growth :Calculate difference between current month and previous month sales.

CREATE TABLE sales_table (
    month DATE,
    sales DECIMAL(10,2)
);

INSERT INTO sales_table (month, sales)
VALUES
('2024-01-01', 10000),
('2024-02-01', 12000),
('2024-03-01', 9000),
('2024-04-01', 15000),
('2024-05-01', 18000);

select * from sales_table 

--- Month-over-Month Growth Query

select month , sales,
		sales - lag(sales) over(order by month) as growth
from sales_table

-- If They Ask for Percentage Growth

SELECT 
    month,
    sales,
    LAG(sales) OVER (ORDER BY month) AS prev_sales,
    ((sales - LAG(sales) OVER (ORDER BY month)) * 100.0 
      / LAG(sales) OVER (ORDER BY month)) AS growth_percentage
FROM sales_table;

---
select month ,
	   sales,
	   prev_sales,
	   ((sales-prev_sales) * 100 / prev_sales) as growth_percentage
from (
	select 
			month,
			sales,
			lag(sales) over (order by month) as prev_sales
	from sales_table
) t;

Q)5:
Interviewer may say:

We are analyzing revenue performance.
The business wants to know how much revenue increased or decreased compared to previous month.
Write a SQL query to calculate month-over-month revenue difference.

If Table is daily Data: 

order_date | amount |

Then we must first aggregate monthly 

with monthly_sales As (
	select 
		Dateformat(year(order_Date),month(order_date) ,1) as month,
		sum (amount) as total_sales
	from orders
	group by year(order_date),month(order_date)
)

Select 
		month,
		total_sales,
		total_sales - lag(total_sales) over (order by month) as growth
from monthly_sales 
interview_answare:
I use DATEFROMPARTS to generate a proper date representing the first day of each month.
This ensures correct grouping, sorting, and compatibility with window functions for time-based analysis.

How To Explain This in Interview (Simple & Clear)
--------------------------------------------------
You can say:

The table contains daily order data, so first I aggregate revenue at a monthly level using a CTE.
I generate the first day of each month using DATEFROMPARTS so that I get a proper date column for correct sorting.
Then I use the LAG window function to get the previous month's total sales.
Finally, I subtract previous month sales from current month sales to calculate month-over-month growth.
